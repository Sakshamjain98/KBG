# 🚀 KBG – Modern Web Application

KBG is a modern, scalable web application built using React and Firebase, designed to deliver a fast, responsive, and serverless user experience.

This project showcases how frontend-focused architectures combined with Firebase can power real-time applications without the need for a traditional backend.

---

## 🌐 Live Demo

https://kbg.sakshamjain.codes/

---

## ✨ Features

- Clean and modern UI/UX  
- Fully responsive design  
- Firebase Authentication for secure access  
- Firestore database for real-time data handling  
- Firebase Storage for media management  
- Fast and optimized performance  
- Serverless architecture  
- Scalable and maintainable code structure  

---

## 🛠️ Tech Stack

Frontend:
- React.js  
- Tailwind CSS  

Backend / Services:
- Firebase Authentication  
- Firebase Firestore (Database)  
- Firebase Storage  

Deployment:
- Vercel (Frontend)  
- Firebase (Backend Services)

## ⚙️ Getting Started

### Clone Repository

git clone https://github.com/your-username/kbg.git  
cd kbg  

---

### Setup Environment Variables

Create a `.env` file:

REACT_APP_FIREBASE_API_KEY=  
REACT_APP_FIREBASE_AUTH_DOMAIN=  
REACT_APP_FIREBASE_PROJECT_ID=  
REACT_APP_FIREBASE_STORAGE_BUCKET=  
REACT_APP_FIREBASE_MESSAGING_SENDER_ID=  
REACT_APP_FIREBASE_APP_ID=  

---

### Install Dependencies

npm install  

---

### Run Development Server

npm start  

App will run on: http://localhost:3000  

---

## 📦 Production Build

npm run build
